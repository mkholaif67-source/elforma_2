# تشغيل المشروع في Android Studio

1. فك ضغط المشروع كاملًا في مجلد جديد
2. افتح مجلد ElForma/mobile من Android Studio
3. استخدم Flutter 3.38 أو أحدث وJDK 17 للبناء
4. افتح Terminal داخل mobile ونفّذ

```powershell
flutter clean
flutter pub get
flutter run
```

شغّل المحاكي أولًا أو اختره من قائمة الأجهزة ثم اضغط Run
لا تحتاج إلى هاتف حقيقي طالما المحاكي يعمل

مجلد android مرفق كاملًا ولا تحتاج إلى flutter create أو نسخ ملفات raw يدويًا
ملف local.properties خاص بجهازك ويجهّزه Flutter عند البناء ولا يوزع مع المشروع
أول بناء يحتاج اتصالًا بالإنترنت لتنزيل أدوات Android واعتماديات Gradle وFlutter

## سبب المشكلة والإصلاح

المجلد السابق كان يحتوي على أصوات التنبيهات فقط، دون AndroidManifest.xml أو MainActivity وإعدادات Gradle
أضيفت ملفات منصة Android التي تعلن flutterEmbedding=2 وMainActivity المبني على FlutterActivity الحديث
أضيف ملف network_security_config.xml الذي كان ملف التعديلات المرسل يشير إليه دون إرفاقه
أرفقت gradlew وgradlew.bat وgradle-wrapper.jar الرسمية، مع التحقق من بصمات SHA-256
أصوات raw الثلاثة محفوظة كما هي
حوّلت imports المحلية إلى package:elforma لإزالة التنبيهات الظاهرة في Android Studio
تنبيهات الإملاء لكلمة Forma ليست أخطاء بناء

ملف التعديلات القديم مبني على إصدار أقدم، ولذلك دُمجت إصلاحاته المطلوبة مع الحفاظ على أحدث الإنترو والأونبوردنج وتعديلات صفحتي الدخول وإنشاء الحساب
