# 🗄️ النقل من قاعدة بيانات لقاعدة

## المبدأ الأساسي

قاعدتك **SQLite** — أكتر فورمات قواعد بيانات محمول في الكوكب. Turso مجرد
"SQLite عبر الشبكة" — نفس الفورمات بالظبط. يعني الداتا مش محبوسة عند حد.

الكود فيه حد واحد للتبديل: `lib/persistence/database-adapter.js` —
بتغيّر متغير واحد (`EF_DATABASE_ENGINE`) والكود كله مابيحسش بالفرق.

## الخيارات المتاحة دلوقتي

| الوضع | القيمة | إمتى تستخدمه |
|---|---|---|
| **Turso سحابي** (الحالي) | `EF_DATABASE_ENGINE=turso` + `EF_TURSO_MODE=remote` | الافتراضي — الداتا تعيش بره السيرفر فبتنجو من أي deploy |
| **SQLite محلي** | `EF_DATABASE_ENGINE=sqlite` + قرص دائم + `EF_STORAGE_DURABLE=1` | أسرع وضع ممكن (صفر شبكة) — مثالي على VPS |
| **Turso replica** | ⚠️ **معطّلة** | شوف القصة تحت |
| **Postgres** | لسه | الفتحة موجودة في الكود (`pg-adapter.js`) — ترقية مدروسة لما العدد يكبر |

## ⚠️ قصة الـ replica (ليه متعطلة — 9 سبتمبر 2026)

جربنا `EF_TURSO_MODE=replica` (نسخة محلية بتتزامن = قراءات فورية).
النتيجة من لوج الإنتاج: `WalConflict` عند frames ‏97 ← 105 ← 149‏ —
القاعدة اتكتب عليها شهور بوضع remote المباشر، فتوليد الـ WAL على الـ primary
بيرفض أي ريبليكا جديدة. **الداتا ما ضاعتش حاجة منها** — بس الإقلاع كان بيقع.

الوضع الحالي: الكود فيه حارس — لو replica اتفعلت بالغلط، السيرفر بيشتغل
`remote` عادي بدل ما يقع. الرجوع للريبليكا محتاج قاعدة Turso **جديدة**
(dump/restore) — خطوة مستقلة لو احتجناها.

## 🔄 Turso → ملف محلي (تصدير واستيراد)

```bash
# 1) صدّر كل الداتا من Turso (أداة turso الرسمية)
turso db shell <اسم-القاعدة> ".dump" > backup.sql

# 2) حوّلها لملف SQLite محلي
sqlite3 elforma.db < backup.sql

# 3) حط الملف في مكان القرص الدائم وشغّل:
EF_DATABASE_ENGINE=sqlite EF_DATA_DIR=/path/to/data EF_STORAGE_DURABLE=1
```

نفس الجداول، نفس الفهارس — السيرفر بيتحقق من التوافق عند الإقلاع لوحده
(`db-contract` + سجل المايجريشن) وبيشتغل.

## 🔄 ملف محلي → Turso (العكس)

```bash
turso db create <اسم-جديد>
turso db shell <اسم-جديد> < backup.sql
```

وبعدين حدّث `TURSO_DATABASE_URL` + `TURSO_AUTH_TOKEN` في اللوحة.

## قاعدة أمان قبل أي نقل

1. خد `.dump` كامل الأول (سطر واحد فوق).
2. جرّب الاستيراد على نسخة **تجريبية** قبل الأساسية.
3. النقل بيتم في دقائق — والداتا الأصلية متبقاش إلا لو مسحتها إنت بنفسك.

## ملحوظة عن النسخ الاحتياطي اليومي

`lib/backup-scheduler.js` بيعمل نسخ دورية — بس على نفس القرص.
**الوضع الحالي (Turso remote) أصلًا بيحميك من موت السيرفر** لأن الداتا بره.
الخطوة الأقوى: تصدير `.dump` دوري لمكان تالت (Drive/S3) — دي خطوة مستقبلية
بتحتاج بيانات دخول منك للوجهة اللي هتختارها.
