# تسليم إصلاح الخانات والكيبورد وبدء الجلسة — 20 سبتمبر 2026

الأساس: ElForma-Onboarding-v7.zip، المبني على آخر مشروع Workout History Analytics.

## التغييرات
- auth_screen.dart: أُلغي تحجيم شاشة الإدخال كلها بواسطة FittedBox والمعتمد على ارتفاع الشاشة. نموذج واحد بتخطيط طبيعي لكل المقاسات؛ الكيبورد يقلل مساحة العرض الرأسية القابلة للتمرير فقط. الصورة والشعار بنفس الأصول والألوان، وحجمهما يعتمد على العرض. حقول الإدخال بحد أدنى 56 نقطة وخط 16، مع التفاف التلميحات والأخطاء. ظهور تأكيد كلمة المرور يضيف حقلًا طبيعيًا ولا يصغّر الصفحة. أُلغي احتساب مساحة الكيبورد مرتين. بقي منطق المصادقة والتحقق وإظهار التأكيد كما هو.
- training_session_screen.dart: الإحماء أو تخطيه يؤدي مباشرة للتمرين، بلا استبيان نوم/تعب/ألم. الجلسة المستأنفة ذات مجموعات مسجلة تُفتح مباشرة. لا تُرسل إجابات مفترضة. بيانات الجاهزية السابقة وتأثيرها على الجلسات المحفوظة بقيت متوافقة؛ لا تغيير بقاعدة البيانات أو الخادم.
- brand_onboarding_page.dart: حساب ارتفاع العناوين والوصف وشارات النص المتعددة الصفوف، بما في ذلك الحدود، قبل تخصيص مساحة الرسم. الحد الأدنى السابق 190 كان يجبر المحتوى على تجاوز المساحة في بعض الشاشات القصيرة؛ أصبح 96 مع تمرير للنصوص الكبيرة. بقي اختبار المقاسين 320×568 و360×640 كما هو دون تعطيل أو تخفيف.

## حدود التحقق
Flutter runtime غير متاح للتشغيل في هذه البيئة؛ لم يُبنَ APK ولم تُجرَ تجربة Android أو قياسات حركة الكيبورد. نجاح فحوص Node وصياغة Dart لا يثبت مرور اختبارات Flutter أو نجاح GitHub Action. ملف GitHub Actions وبوابة الاختبارات محفوظان دون تجاوز. التحقق المتبقي هو تشغيل نفس مسار GitHub المعتاد وتجربة الخانات وفتح/إغلاق الكيبورد والتنقل بينها على الهاتف، بما في ذلك حجم خط كبير. لا توجد ادعاءات بقياس FPS أو أداء الجهاز.

لم تُمس ملفات Form Coach أو التغذية أو الاشتراكات أو سجل التدريب والتحليلات، ولم تُحذف أي ملفات أو صور. الدوال القديمة الخاصة برسم نموذج المصادقة بإحداثيات ثابتة أزيلت بعدما استُبدلت بمسار العرض الطبيعي؛ لم يُحذف منطق المصادقة.
