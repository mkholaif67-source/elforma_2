# 🔑 المتغيرات والمفاتيح — اللى كنت أعمى فيها

## فين بتتعرف المتغيرات؟ (ترتيب الأولوية — الأعلى بيكسب)

```
1) لوحة Render (Environment)        ← اليدوي بيغلّب كل حاجة
2) render.yaml في الكود             ← المصدر المُدار (أي deploy بيرجّع ليه)
3) القيم الافتراضية جوه الكود        ← لو الاتنين فوق ساكتين
```

> ⚠️ الدرس اللي اتعلمناه 9 سبتمبر: لو غيّرت قيمة من اللوحة وبعدين رفعت كود فيه
> نفس المتغير في render.yaml — **اللوحة بتفضل غلّبة**. عشان كده القاعدة:
> **التغييرات الدائمة في render.yaml، والأسرار بس في اللوحة.**

## جدول المتغيرات الكامل

### أسرار (في اللوحة بس — `sync: false` — مابتتكتبش في الكود أبدًا)

| المتغير | وظيفته | لو ضاع/اتغير |
|---|---|---|
| `EF_SECRET` | توقيع الجلسات | **كل المستخدمين هيتطلعوا فورًا.** انسخه واحفظه عندك في مكان آمن |
| `TURSO_DATABASE_URL` | عنوان قاعدة Turso | السيرفر مابيلاقيش القاعدة |
| `TURSO_AUTH_TOKEN` | مفتاح قاعدة Turso | نفس اللي فوق |
| `REDIS_URL` | كاش مشترك (اختياري دلوقتي) | لو فاضي: الكود بيشتغل بكاش محلي عادي |
| `EF_MAIL_API_URL` / `EF_MAIL_API_KEY` / `EF_MAIL_FROM` | مزود الإيميلات (تحقق + استرجاع باسورد) | لو فاضيين: الإيميلات بتتكتب في outbox محلي ومابتوصلش لحد — **لازم يتظبطوا قبل الإطلاق الحقيقي** |
| `EF_ADMIN_SETUP_TOKEN` | استرجاع طوارئ لحساب الأدمن | امسحه بعد أول استخدام |

### إعدادات مُدارة من render.yaml

| المتغير | قيمته | وظيفته بلغة بسيطة |
|---|---|---|
| `EF_ENV` | `production` | يفعّل كوكيز Secure (HTTPS) |
| `EF_TRUST_PROXY` | `"1"` | يقول للسيرفر إن وراه موزّع Render (عشان الـ IP الحقيقي) |
| `NODE_OPTIONS` | `--experimental-sqlite` | **حتمي** — من غيره node:sqlite مابيشتغلش والسيرفر مابيقلعش |
| `EF_ADMIN_EMAILS` | إيميلك | مين يقدر يفتح لوحة الأدمن |
| `EF_DATA_DIR` | `/tmp/elforma` | مكان الملفات المؤقتة (على المجاني بيتمسح مع كل deploy — وده عادي لأن الداتا الدائمة على Turso) |
| `EF_DATABASE_ENGINE` | `turso` | اختيار القاعدة: `turso` أو `sqlite` (محلي) — التفاصيل في `04-MOVE-DATABASE.md` |
| `EF_REQUIRE_DURABLE_DB` | `"1"` | يمنع الإقلاع لو القاعدة مش دائمة (حماية من ضياع البيانات) |
| `EF_TURSO_MODE` | `remote` | **متحولهاش لـ replica** — معطّلة بسبب WalConflict، والكود بيحمي نفسه لو اتغيرت غلط |

### إعدادات اختيارية ليها افتراضي في الكود

| المتغير | الافتراضي | فايدته |
|---|---|---|
| `PORT` | `8000` | منفذ السيرفر |
| `EF_BASE_URL` | — | الرابط العام — بيستخدم في روابط الإيميلات (لازم يبقى الدومين الصح) |
| `EF_BACKUP_KEEP` | `30` | كام نسخة احتياطية محلية يحتفظ بيها |
| `ENGINE_POOL_SIZE` | تلقائي (1–2) | عدد عمال حساب الخطط |
| `ENGINE_TASK_TIMEOUT_MS` | `15000` | أقصى وقت لحساب خطة قبل الرفض |
| `EF_LOG_REQUESTS` | `1` | سطر JSON لكل طلب API (أساس المراقبة) |
| `EF_LOG_IP` | `1` | حطه `0` لو عايز تخفي الـ IP من اللوجز خالص |
| `EF_PERF_HEADERS` | — | حطه `1` مؤقتًا عشان تشوف زمن الـ SQL في هيدر `Server-Timing` |

## 📱 متغير مهم بره السيرفر خالص: عنوان السيرفر جوه التطبيق

في `mobile/lib/api.dart` سطر 59:

```dart
static const String baseUrl = String.fromEnvironment(
  'EF_BASE_URL',
  defaultValue: 'https://elforma.onrender.com',
);
```

**معناه:** عنوان السيرفر بيتخبز جوه الـ APK وقت البناء. الـ CI دلوقتي مابيمررش
قيمة مختلفة، فالافتراضي هو اللي شغال. لو يومًا غيّرت الدومين، لازم:

```bash
flutter build apk --dart-define=EF_BASE_URL=https://الدومين-الجديد.com
```

والمستخدمين يحدّثوا التطبيق. (نصيحة ذهبية: **ثبّت دومين خاص بيك بدري** —
كده النقل بين الاستضافات يبقى مجرد توجيه DNS، والتطبيق مابيتكسرش.)
