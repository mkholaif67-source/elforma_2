# تحسين النسخة الجديدة فقط

المصدر: ElForma-Flutter(1).zip الذي أرسله المستخدم في هذه الدفعة.

- الصور الأصلية الأربع بقيت كما هي، بدقة 1200 × 1677، دون قص أو إعادة توليد أو استبدال.
- كروت الصور كانت نصوص Flutter بالفعل، لكنها كانت داخل FittedBox مع الصورة. أصبحت مواضع الكروت تتبع الصورة، بينما أحجام خطوطها مستقلة: 13.5 للنص الصغير، و15 للتعليقات، و16 للافتة. ارتفاع الكارت يُحسب من النص الفعلي وحجم الخط، وليس ارتفاعًا ثابتًا يقص الكلام.
- اللافتة الخضراء لها تدرج وحدود خفيفة وعمق. النصوص الحالية والعناوين والوصف محفوظة.
- عند تكبير خط النظام بدرجة كبيرة، تظهر تفاصيل المشهد كنص قابل للتمرير أسفل الرسم بدل تراكب الكروت فوق بعضها.
- زر التنقل بقي بسهم لليسار، مع حد أدنى 148 × 52.
- شاشة الدخول في المساحات القصيرة تمنح الهيدر المساحة المتبقية بعد النموذج، مع تقليل الفراغات ومساحة الزخرفة السفلية. الوصف الترحيبي الثانوي يظهر عند توافر الارتفاع. الصورة تستخدم cover بدل fill لتجنب تشويه نسبها. الخانات تحتفظ بحدها الأدنى 56.
- إنشاء الحساب يحتفظ بتوزيع مستقل وبالتمرير عند الحاجة؛ لا ضغط للنموذج كاملًا.

التحقق المنفّذ: تنسيق وتحليل الصياغة بـDart؛ فحوص المصدر للأصول وإمكانية الوصول نجحت؛ حساب إظهار الحقل نجح في 493 حالة باستخدام Dart مستقل. أُضيف اختبار Flutter لاحتواء شاشة الدخول في 320×568 و360×640 و393×852 دون تمرير في الوضع العادي.

لم يتوفر Flutter runtime أو Android هنا؛ اختبارات الواجهة الجديدة وflutter analyze وبناء APK لم تُشغّل. لذلك لا توجد دعوى بتطابق بصري 100% أو نجاح اختبار الهاتف. الاختبارات محفوظة في المشروع لتعمل ضمن مسار GitHub الحالي.

التغييرات محصورة في ملفي الواجهة واختبار الحسابات وهذه الوثيقة. لا تعديل لمحركات التدريب والتغذية أو Form Coach أو APIs، ولا حذف لأي ملف أو أصل من النسخة الجديدة.
